# v0.8.8 패널 API 키 설정 및 연결 테스트

기존 유튜브 패널에서 **설정 → API 키 설정 · 연결 테스트**를 누른다. 새 탭 없이 Chrome 확장 팝업을 열어 OpenAI 키를 저장·교체·삭제한다. 이어서 **번역·음성 연결 테스트**로 짧은 문장을 실제 GPT 번역 및 Realtime 음성으로 생성하며, 성공하면 재생 컨트롤을 표시한다. 키 저장 자체는 인증 성공을 의미하지 않는다.

## 저장 및 접근 범위

- 키 입력은 유튜브 DOM과 분리된 확장 프로그램 출처에서만 수행한다. 해당 문서만 백그라운드 키 설정 메시지를 보낼 수 있다.
- 키는 브라우저 저장소·콘텐츠 스크립트·URL·응답으로 전달하지 않는다. 입력칸은 저장 요청 직전에 비운다.
- 로컬 백엔드의 `backend/.env.panel.local`에 0600 권한으로 원자적으로 저장하고 즉시 적용한다. Git에서 제외된다. OS 키체인 암호화 저장은 아니다.
- 재시작 시 패널 설정이 기존 환경 파일보다 우선한다. 키 삭제는 패널 파일에 빈 값을 저장해 이전 환경 키가 다시 활성화되지 않게 한다. 이전 환경 파일 자체를 수정하지 않는다.
- 설정 요청은 loopback 호스트, JSON, 확장 출처/전용 헤더를 요구한다. 외부 웹 출처·다른 확장 페이지·과대 요청·개행 키를 거부한다.
- 저장·삭제·테스트는 동시에 하나만 수행한다. 테스트 중 키 교체를 거부하며 실패 후 잠금을 해제한다.

## 검증

2026-11-10 macOS 실제 서버 요청. 사용자가 패널에서 OpenAI 키를 저장한 후 확인했으며 키 값은 출력하지 않았다. 재시작 후에도 등록 상태가 유지됨을 확인했다.

| 경로 | 결과 |
| --- | --- |
| 모두 로컬 | HTTP 200, 4.871초, 314,036바이트 / 3.56초 WAV |
| Gemma → GPT 음성 | HTTP 200, 5.267초, 실제 Realtime 호출, 134,444바이트 / 2.8초 WAV |
| GPT 번역 → 로컬 음성 | HTTP 200, 6.720초, 번역 캐시 적중 0, 437,516바이트 / 4.96초 WAV |
| GPT 번역 → GPT 음성 | HTTP 200, 4.565초, 번역 캐시 적중 0, 206,444바이트 / 4.3초 WAV |
| 패널 연결 테스트 | 실제 번역·음성 호출 성공, 팝업 표시 3.7초, 약 3.1초 음성 재생 확인 |

사용 모델: GPT 번역 `gpt-6-luna`, GPT 음성 `gpt-realtime-2.1-mini`. 실제 GPT 번역+음성 테스트 원문: “The robot carries twenty-three boxes across the room.” 번역: “로봇이 방을 가로질러 상자 스물세 개를 옮깁니다.”

기존 유튜브 탭의 설정 버튼에서 전용 팝업 열기, 미등록 상태 표시, 키 없이 테스트할 때 등록 안내를 실제 Chrome에서 확인했다. 사용자가 키를 저장한 뒤 같은 팝업에서 연결 테스트 성공 및 음성 재생 상태(일시중지 버튼과 진행 중 오디오 시간)를 확인했다. 새로운 탭은 만들지 않았다.

처음 수행한 일반 더빙 요청에서 GPT 번역 캐시 적중을 발견해, 새 원문으로 다시 검사하고 캐시 적중 0을 확인했다. 패널의 연결 테스트는 별도로 캐시를 우회해 매번 실제 번역 및 음성 API를 호출한다. 같은 문장을 다시 테스트해도 인증·모델 권한을 실제로 검증한다.

`npm run test:cloud`: 전체 139개 통과. 저장/삭제 후 재시작, 응답의 키 비노출, 파일 권한, 출처/호스트 검증, 크기/형식 검증, 동시성, 확장 페이지 권한 경계, 반복 연결 테스트의 실제 공급자 호출을 포함한다. Mock 단위 테스트와 실제 API 응답을 구분해 검증했다. Windows/Linux의 실제 Chrome 팝업·음성 재생은 미검증이다.

Chrome 127 이상 팝업 API 사용: [Chrome action API](https://developer.chrome.com/docs/extensions/reference/api/action).
