# v0.8.9 실제 유튜브 네 모드 검증

2026-11-10, macOS Apple Silicon의 기존 Chrome 유튜브 탭에서 실행했다. 새 브라우저/탭을 만들지 않았고 다운로드 도구에 로그인 쿠키를 전달하지 않았다.

영상: https://www.youtube.com/watch?v=NL65Awuv8gU (Boston Dynamics, 2분 50초). 각 모드는 영상 50초부터 Start를 눌러 약 25초 원음 수집 → 로컬 Whisper 음성인식 → 선택한 번역/음성 엔진 → 실제 HTML 오디오 재생을 거쳤다. 음색은 기본 자동 선택을 유지했으며 소스 다운로드가 불가능해 M1/marin 기본 음색이 사용됐다.

## 재현 및 수정

v0.8.8에서 원음 준비 도중 영상 일시정지를 누르면 `원음 준비가 일시정지되었습니다. Start를 다시 눌러 주세요.` 오류로 세션이 종료되는 것을 재현했다.

v0.8.9는 MediaRecorder도 함께 일시정지하고, 영상 재생 시 이어서 수집한다. 일시정지 동안 준비 타임아웃을 해제하고 재개할 때 남은 구간 기준으로 다시 설정한다. 늦게 도착한 pause 이벤트가 이미 재개된 수집을 중단하지 않도록 보호한다. Stop은 일시정지 중인 recorder도 종료하고 원래 위치·속도·음소거 상태와 트랙을 정리한다. 패널 상단에 원음 준비 진행률과 일시정지 후 재개 안내를 표시한다.

## 실제 실행 결과

| 옵션 | 첫 더빙 | 재생 중 관측 | 일시정지 / 재개 / Stop |
| --- | --- | --- | --- |
| 1. Gemma → Supertonic | 42.36초* | 영상 68.24초, 음성 2.10/3.66초, supertonic-3 | 통과 |
| 2. Gemma → GPT 음성 | 39.48초 | 영상 71.49초, 음성 1.47/2.80초, gpt-realtime-2.1-mini | 통과 |
| 3. GPT 번역 → Supertonic | 39.92초 | 영상 59.88초, 음성 1.08/2.80초, supertonic-3 | 통과 |
| 4. GPT 번역 → GPT 음성 | 38.76초 | 영상 73.84초, 음성 2.02/3.10초, gpt-realtime-2.1-mini | 통과 |

*1번은 원음 준비 중 수동 일시정지/재개 검증 시간이 포함됐다. 최초 재생 시간은 해당 실행의 관측치이며 성능 보장은 아니다. 일반 더빙 경로는 번역/음성 캐시를 사용할 수 있다. 이 표는 모든 클립의 캐시 미사용 API 호출을 입증하는 표가 아니며, 실제 인증/캐시 미사용 API 검증은 `panel-api-v0.8.8.md`에 별도로 기록했다.

1번: 준비 8/25초에서 일시정지해 오류 없이 대기, 다시 재생하여 수집과 더빙 완료. 더빙 일시정지 시 영상 67.72초와 음성 1.87/3.66초가 함께 멈췄고 재개 시 두 재생 시간이 증가했다.

2번: 영상 71.23초, 음성 1.19/2.80초가 함께 일시정지하고 재개됐다. 번역 예: “It's like playing a video game. That's really fun.” → “비디오 게임 같아요. 정말 재미있네요.”

3번: 영상 59.47초, 음성 0.74/2.80초가 함께 일시정지하고 재개됐다. 번역 예: “The point was pushing the actuation to its limits.” → “핵심은 구동을 한계까지 밀어붙이는 것이었어요.”

4번: 영상 73.37초, 음성 1.39/3.10초가 함께 일시정지하고 재개됐다. 다음 원음 구간으로 자동 전환된 뒤 11/25초에서 일시정지, Stop으로 수집 시작 위치 약 74.64초로 복원되고 더빙이 제거됐다.

네 모드 모두 Stop 후 원본 음량 100%, 음소거 해제, 더빙 없음 상태를 확인했다. 테스트 종료 후 영상은 일시정지하고 패널 원본 음량 설정은 사용자 값 8%로 돌려놓았다.

## 자동 검사와 한계

- 변경 전 `npm run test:cloud`: 139개 통과.
- 변경 후 `npm run test:cloud`: 141개 통과. 수집 일시정지/재개/일시정지 중 Stop 및 지연 pause 이벤트 회귀 검사 추가. 이 검사는 mock이며 위 브라우저 실행과 구분한다.
- `git diff --check` 통과.
- 자막 없는 영상은 25초 원음을 먼저 재생하며 수집하고 원래 위치로 돌아와 더빙한다. 다음 구간에서도 준비 대기가 발생한다. 즉시/무중단 더빙은 아니다.
- 실제 브라우저 검증은 이 Mac과 이 영상 구간에서 수행했다. Windows/Linux 실기기, 장시간 전체 영상, 다른 영상과 광고 전환의 동작은 이번 검증 범위에 포함하지 않는다.
